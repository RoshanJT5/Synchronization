What Does the Chrome Extension Do?

The Synchronization Chrome Extension is the sender half of the wireless audio system. It uses Chrome's built-in tabCapture API to capture the audio playing in whichever browser tab you select — whether that is a video, a music player, a podcast, or any other audio source.

Once capture begins, the extension generates a unique QR code for your current session. You scan this QR code with the Synchronization Android app to pair your devices instantly. The audio is then streamed directly from your computer to your phone over WebRTC — peer-to-peer, with no cloud relay in the middle.

There is no sign-up, no API key, and no account required. Click the extension icon, press Start Streaming, scan the QR code, and your phone starts playing the audio within two seconds.

How to Install the Extension in Chrome

  1. Download the ZIP — Click the download button above and save the synchronization-extension.zip file to your computer.
  2. Extract the ZIP — Right-click the downloaded file and choose Extract All (Windows) or double-click to open it (macOS). Extract to a permanent folder — do not delete the folder after loading, Chrome needs it to stay there.
  3. Open Chrome Extensions — In Google Chrome, type chrome://extensions in the address bar and press Enter.
  4. Enable Developer Mode — Toggle the Developer mode switch in the top-right corner of the Extensions page to the on position.
  5. Load unpacked — Click the Load unpacked button that appears after enabling Developer mode. In the file picker, navigate to and select the extracted extension folder.
  6. Pin the extension — Click the puzzle icon in the Chrome toolbar, find Synchronization in the list, and click the pin icon so it always appears in your toolbar.
Important: Do not move or delete the extracted extension folder after loading it. Chrome loads the extension directly from that folder every time. If you move it, the extension will stop working and you will need to load it again.

System Requirements

The extension requires Google Chrome running on a desktop or laptop computer — Windows, macOS, or Linux. Chromium-based browsers such as Microsoft Edge or Brave may also work, though they are not officially tested.

To receive the audio, you need the Synchronization Android app installed on an Android device (version 7.0 or later) connected to the same Wi-Fi network or mobile hotspot as the computer running the extension. An active internet connection is also required for play and pause controls to communicate between your devices.

Why Is It a ZIP and Not on the Chrome Web Store?

Synchronization is currently distributed as a manually-loaded unpacked extension rather than through the Chrome Web Store. This allows us to ship updates immediately without waiting for Google's review queue, and gives you the latest version directly from our official domain (synchronizationpro.app).

Manual loading is straightforward and takes less than two minutes. Once loaded, the extension updates when you download and reload a new version — the process is identical to the initial install.
